# 🔐 iBijan Pass
**Smart, Offline, and Custom-Pattern Password Generator**

iBijan Pass (formerly SPG) is a secure, cross-platform desktop application that generates highly customizable passwords. It features a built-in encrypted vault and profile management system to keep your accounts safe.

🌐 **Website:** [ibijan.com](https://ibijan.com)

## ✨ Features

- **Custom Generation Patterns:** Define how your password is constructed (Prefix, Base Number, Special Characters, etc.).
- **Military-Grade Encryption:** All data and profiles are encrypted using AES-128 (Fernet).
- **Master Password Protection:** Your vault and profiles are locked behind a master password.
- **Secure Profiles (🔒):** Request an extra layer of authentication for highly sensitive accounts (e.g., Banking).
- **Encrypted Vault:** Save generated passwords securely.
- **Import/Export:** Easy backup and restore with option for separate encryption keys.
- **Cross-Platform:** Works on Linux, macOS, and Windows.
